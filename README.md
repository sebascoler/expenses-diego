# Expenses Diego

Herramienta web para preparar la rendición mensual de gastos de Diego: importa los movimientos de Wise y BBVA, los clasifica (empresa o personal, viaje, categoría) y calcula km y peajes. Al final genera el PDF, el Excel, el borrador del mail y el importe a facturar.

- Requisitos completos: [`docs/PRD.md`](docs/PRD.md)
- Stack: Next.js en Vercel, Neon Postgres, Resend y Claude API
